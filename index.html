Mod Creator Tutorial

⚔️ created by RayTatsu

Learn how to build and export custom champions for Teamfight Manager 2.

📌 1. Project Overview

This visual tool helps you create and configure custom champions for **Teamfight Manager 2**. When you export, it generates a complete zip file containing the correct file structures (like .data_champion, champion.i18n, champion_view.champion_view, and #anim.fanim) mapped under mods/[your_mod_id]/.

Pro-Tip: The Mod ID (set in the first tab) is used as the directory name and unique asset prefix. Make sure it is in lowercase_snake_case!

🗂️ 2. Tab Directory

  • Mod Info: Set Mod metadata (ID, Author, Name, Version, Last Updated date) and base game dependency.
  • Champion: Set identification name, category (e.g. Melee Physical), classifications tags, view coordinate offsets, and import i18n files for compatibility.
  • Stats & Growth: Base values at Level 1 and Level growth coefficients (which add to stats each level up).
  • Actions & Skills: Define champion combat abilities. Set durations, ranges, and action effects (Basic Attack, Skill 1, Skill 2, Ultimate).
  • Visual Bindings: Tie in-game projectiles, effects, and buffs to specific sprites from the game files.
  • Sprite Sheet: Upload PNG sheets, set grid size, extract animations, and build .fanim.
  • Descriptions: Write localized names and descriptions for your champion and skills in English and Portuguese.
  • Recipes: Quick pre-configured effect recipes (CC, Buffs, AP Damage) to insert instantly into actions.

🌟 3. The Champion Sheet (Translation Engine)

The **Champion Sheet** tab is one of the most important components of this tool! It has two main functions:

  1. Action Translation Engine: Constructing complex action structures (like nesting child effects under Combine or Branch actions) creates a large nested JSON block that is hard to read.
    The **Champion Sheet automatically parses your nested action JSON** and translates it into simple, human-readable skill descriptions (e.g. "Deals 120% AP Damage, stuns targets in range for 1.5 seconds, and grants a shield..."). This acts as a mechanical validator for your abilities!
  2. Live Animation Player: Renders real-time animation canvases playing your sprite ranges (Idle loop, Attack sequence, Skill animations) directly in the mock card!
If animations do not update after you adjust range numbers in the Sprite Sheet tab, click the 🔄 Refresh Animations button on the Champion Sheet tab header to recalculate frames immediately.

💾 4. Saving & Loading Existing Mods

To avoid losing progress, use the buttons at the bottom of the sidebar:

  • Save JSON: Downloads a single .json file representing your entire workspace state. You can reload this at any time.
  • Load Mod Folder: You can select an entire local mod folder (like mods/dio_mod) directly from your computer! The creator will automatically load and parse the data champion, spritesheets, animation ranges, descriptions, and offsets, restoring the entire workspace for editing!

Tutorial do Criador de Mods

⚔️ created by RayTatsu

Aprenda a construir e exportar campeões customizados para o Teamfight Manager 2.

📌 1. Visão Geral do Projeto

Esta ferramenta visual ajuda você a criar e configurar campeões customizados para o **Teamfight Manager 2**. Quando você exporta, ela gera um arquivo ZIP completo contendo as estruturas de pastas e arquivos corretos (como .data_champion, champion.i18n, champion_view.champion_view e #anim.fanim) mapeados sob mods/[seu_id_de_mod]/.

Dica Pro: O Mod ID (definido na primeira aba) é usado como nome da pasta e prefixo único dos arquivos. Certifique-se de que esteja escrito em lowercase_snake_case!

🗂️ 2. Guia de Abas

  • Mod Info: Define metadados do mod (ID, Autor, Nome, Versão, Data da última atualização) e dependência básica do jogo.
  • Champion: Define nome identificador, categoria (ex: Melee Physical), tags de classificação, coordenadas visuais e importação de arquivos i18n para compatibilidade.
  • Stats & Growth: Atributos básicos no Nível 1 e coeficientes de crescimento por nível (adicionados aos atributos a cada level up).
  • Actions & Skills: Define as habilidades de combate do campeão. Configure durações, alcances e efeitos de ação (Ataque Básico, Habilidade 1, Habilidade 2, Suprema).
  • Visual Bindings: Conecta projéteis, efeitos visuais e buffs de status aos sprites correspondentes nos arquivos do jogo.
  • Sprite Sheet: Envia a folha de sprites PNG, configura linhas/colunas, define o tempo de cada frame e mapeia as animações (Idle, Corrida, Ataque, etc.).
  • Descriptions: Escreve nomes e descrições localizadas das habilidades do seu campeão em Inglês e Português.
  • Recipes: Fórmulas pré-configuradas de efeitos comuns (Controle de Grupo, Buffs, Dano de PA) para inserir instantaneamente nas suas ações.

🌟 3. A Ficha do Campeão (Champion Sheet - Motor de Tradução)

A aba **Champion Sheet** é um dos componentes mais importantes desta ferramenta! Ela possui duas funções principais:

  1. Motor de Tradução de Ações: Construir estruturas de efeitos complexas (como efeitos filhos dentro de uma ação do tipo Combine ou Branch) gera blocos aninhados de JSON difíceis de ler.
    O **Champion Sheet analisa automaticamente o JSON da ação** e o traduz em descrições legíveis em linguagem humana (ex: "Causa 120% de Dano de PA, atordoa alvos no alcance por 1.5 segundos e concede um escudo..."). Isso serve como validador das suas mecânicas!
  2. Reprodutor de Animações em Tempo Real: Renderiza telas de animação em tempo real que reproduzem seus frames (loop de Idle, sequência de Ataque, animações de Skill) diretamente no card visual do campeão!
Se as animações não atualizarem após você ajustar os números de frames na aba Sprite Sheet, clique no botão 🔄 Refresh Animations no topo do cabeçalho da Champion Sheet para recalcular os frames imediatamente.

💾 4. Salvar e Carregar Mods Existentes

Para não perder seu progresso, use os botões na parte inferior da barra lateral:

  • Save JSON: Baixa um arquivo .json contendo todo o estado atual do seu criador. Você pode carregá-lo a qualquer momento.
  • Load Mod Folder: Você pode selecionar uma pasta de mod local inteira (como mods/dio_mod) diretamente do seu computador! O criador lerá e importará automaticamente o data champion, spritesheets, animações, descrições e offsets, restaurando todo o ambiente de trabalho!

📖 Recipe Import Template

Below is a template JSON showing how to import custom recipes from outside. You can copy this JSON, modify it, and import it into the recipe book.

Field Descriptions:

  • title: (Required) Name of the recipe.
  • desc: Description of what the recipe does.
  • category: The category to group this recipe under (e.g. Basic Attack, Buffs, CC).
  • pairing: Guidance notes on which action properties this recipe fits.
  • image: (Optional) A web URL or a Base64 data URL string (e.g. data:image/png;base64,...).
  • json: (Required) The recipe configuration. This can be a **full action object** (duration, cooltime, range, casting, and nested effect) or an **effect-only object** (type and its properties). It can be specified either as a stringified JSON string or as a direct nested JSON object in the file.
